# Application web — École à jour

Interface Next.js de la plateforme de gestion scolaire.

## Démarrage

Depuis la racine du dépôt :

```bash
npm run dev
```

Ou uniquement le front, une fois l’API démarrée :

```bash
cd web
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans le navigateur.

## Rôle de ce dossier

Le dossier `web/` contient le portail (administration, enseignants, élèves, parents, personnel) qui parle à l’API `server/`.
